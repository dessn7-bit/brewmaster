## 1. web_fetch aracı, web_search sürümleri, arama + çekme birleşimi

### Takeaway
web_fetch, sayfanın/PDF'in TAM metnini yanıt içinde düz metin `document` bloğu olarak döndürür, ek ücreti yoktur (yalnız token), `max_content_tokens`, `allowed_domains`, `max_uses` ve isteğe bağlı citations destekler; web_search ise sonuç içeriğini şifreli verir ve `cited_text` en fazla 150 karakterdir — CEV'deki %49 kesik alıntının doğrudan nedeni budur. Aynı istekte web_search + web_fetch birlikte çalışır (Claude önce arar, bulduğu URL'yi çeker).

### Cited Findings
- web_fetch "retrieve full content from specified webpages and PDF documents"; en yeni sürüm `web_fetch_20260318` (dinamik filtreleme + response inclusion); diğer sürümler `web_fetch_20260309` (dinamik filtreleme + cache bypass), `web_fetch_20260209` (yalnız dinamik filtreleme), `web_fetch_20250910` (temel). Durum: stable (beta başlığı gerekmez). — [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)
- Desteklenen modeller listesinde claude-opus-5-5, claude-sonnet-5-5, claude-haiku-5-5 (ve Fable 5.1) var; dinamik filtreleme "Claude 4.6 and later models" ile çalışır. — [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)
- Sonuç biçimi: `web_fetch_tool_result` → `content.type: "document"`, `source: {type:"text", media_type:"text/plain", data:"Full text content of the article..."}`, `title`, `retrieved_at`; PDF'ler base64 olarak döner ve "processes it like a directly attached PDF document". ZDR notu: "Fetched web content returned in the API response." — [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)
- Parametreler: `max_uses` (varsayılan sınır yok; başarısız çekmeler de sayılır; aşınca `max_uses_exceeded`), `allowed_domains`/`blocked_domains` (ikisi birlikte olmaz), `url_sources`, `citations: {enabled: true}`, `max_content_tokens` (aşılırsa içerik kırpılır; yaklaşık; PDF gibi ikili içeriğe uygulanmaz), `use_cache` (20260309+), `response_inclusion` (20260318+). — [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)
- Citations web_fetch'te İSTEĞE BAĞLI ve varsayılan kapalı ("Unlike web search, where citations are always enabled"); açılınca yanıt `char_location` tipinde `start_char_index`/`end_char_index`/`cited_text` içerir. — [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)
- Fiyat: "no additional charges beyond standard token costs"; örnek boyutlar: ortalama sayfa (10 kB) ≈ 2.500 token, büyük doküman sayfası (100 kB) ≈ 25.000 token, araştırma PDF'i (500 kB) ≈ 125.000 token. Kullanım `usage.server_tool_use.web_fetch_requests` alanında raporlanır. — [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool); [Pricing](https://platform.claude.com/docs/en/about-claude/pricing)
- Sınırlamalar: JavaScript ile çizilen siteleri desteklemez; yalnız text, HTML ve PDF (`unsupported_content_type`); URL ≤ 250 karakter (`url_too_long`); `robots.txt`, özel adresler ve organizasyon alan kuralları `url_not_allowed` verir; hatalar HTTP 200 içinde `web_fetch_tool_result_error` olarak döner; sonuçlar Anthropic tarafında önbelleğe alınabilir ("might not always reflect the latest version"). — [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)
- URL doğrulama: Claude yalnız konuşmada daha önce geçmiş URL'leri çekebilir (kullanıcı mesajı, istemci araç sonucu, önceki web_search/web_fetch sonucu); yalnız sistem isteminde ya da Claude'un kendi çıktısında geçen URL çekilemez (`url_not_in_prior_context`). — [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)
- Birleşik kullanım: iki araç da açıksa Claude "Uses web search to find relevant articles… Selects the most promising results… Uses web fetch to retrieve full content… Provides detailed analysis with citations." — [Web fetch tool – Combined search and fetch](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)
- Alan filtresi farkı: web_search alt yol (path) eşleştirir (`example.com/blog`), web_fetch yalnız alan adını eşleştirir ("an entry that includes a path never matches a web fetch URL"); alt alan adları otomatik dahil; joker yalnız yol kısmında; istek düzeyindeki `allowed_domains` Console'daki organizasyon listesinin alt kümesi olmalı. — [Server tools – Domain filtering](https://platform.claude.com/docs/en/agents-and-tools/tool-use/server-tools)
- Bir organizasyon yöneticisi web fetch'i Console ▸ Capabilities sayfasından kapatabilir; kapalıyken araçlı istek 400 `invalid_request_error` verir. — [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool); [Release notes](https://platform.claude.com/docs/en/release-notes/overview)
- web_search sürümleri: `web_search_20250305` (temel), `web_search_20260209` (dinamik filtreleme), `web_search_20260318` (+ response inclusion). 20260209+ sürümlerde `allowed_callers` varsayılanı `["code_execution_20260120"]`; doğrudan çağrı için `allowed_callers: ["direct"]`. Dinamik filtrelemedeki kod çalıştırma "no additional charges… beyond the standard token costs". — [Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool)
- web_search sonuçları: `url`, `title`, `page_age`, `encrypted_content` (çok-turda aynen geri gönderilmeli); citations her zaman açık; `web_search_result_location.cited_text`: "Up to 150 characters of the cited content"; `cited_text`, `title`, `url` token sayımına girmez. — [Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool)
- web_search fiyatı: "$10 USD per 1,000 searches" + arama içeriği input token olarak; sonuçlar aynı tur içindeki sonraki arama iterasyonlarında ve sonraki turlarda yine input token sayılır; hatalı arama ücretlendirilmez. — [Pricing](https://platform.claude.com/docs/en/about-claude/pricing); [Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool)
- Haiku 5.5 fiyatı istem boyuna bağlı: ≤100.000 token $0,10/$0,50; >100.000 token $0,50/$2,50 (MTok başına). — [Pricing](https://platform.claude.com/docs/en/about-claude/pricing)

### Inferences
- %49 kesik alıntı sorunu web_search'ün yapısal sınırı (150 karakter, içerik şifreli); web_search'ün yeni sürümleri bu sınırı değiştirmiyor (doküman her sürüm için aynı alanı tanımlıyor). Kesilmeyi çözen tek belgelenmiş yol, kaynağın TAM metnini bağlama almak: web_fetch.
- En güçlü kullanım: web_fetch sonucu `source.data` alanında düz metin olarak geldiği için Brewmaster, doğrulayıcı (verifier) çağrısından önce ya da yerine, her maddenin alıntısını bu metinde YEREL olarak birebir (normalize edilmiş) arayabilir — model maliyeti sıfır, kesilme yok. Bu, "doğrulanamadı diye düşen doğru madde" oranını doğrudan düşürmeli (VARSAYIM; ölçülmedi).
- Önerilen deneme tasarımı (DENE, M efor): 4 kaynak sınıfı çağrısında `web_search_20250305` yanına `web_fetch_20250910` (temel sürüm, dinamik filtreleme yok — ilk ölçüm için en şeffaf seçenek), `max_uses: 2`, `max_content_tokens: 6000–8000`, aynı `allowed_domains` listesi (web_fetch'te yol içermeyen alan adlarıyla). Maliyet tahmini (VARSAYIM): sınıf başına 2 çekme × ~6.000 token × 4 sınıf ≈ 48.000 ek input token; Haiku 5.5'te ≈ 0,005 $, ama aynı tur içindeki sonraki iterasyonlarda yeniden sayıldığı için 2–3 kat hesaplanmalı; isteğin 100k tokenı aşıp Haiku fiyatını 5 katına çıkarmaması için `max_content_tokens` şart.
- Dikkat: allowed_domains'te yol içeren girdiler (ör. `example.com/blog`) web_fetch'te hiç eşleşmez → mevcut listelerin web_fetch için alan-adı-only kopyası gerekir.
- Dinamik filtreleme (20260209+) token azaltır ama Claude kodun çıktısını okuduğu için alıntının hangi ham metinden geldiği CEV doğrulaması açısından daha az şeffaf olabilir; önce temel sürümle ölçmek daha güvenli (VARSAYIM).
- JS ile render edilen üretici sayfaları (bazı maya/hop üreticileri) web_fetch ile boş/eksik gelebilir; bu yüzden "çekilemedi" durumunda mevcut cited_text yoluna geri düşmek gerekir.

### Gaps
- web_fetch `char_location` alıntılarının pratikte ortalama uzunluğu belgelenmemiş (yalnız "sentence chunking… chain together multiple consecutive sentences" deniyor); ölçülmeden "%49 → X" denemez.
- web_fetch için ayrı bir hız sınırı ya da günlük kota belgelenmemiş (yalnız `too_many_requests` hata kodu var). Bulamadım.
- Hangi demleme sitelerinin (byo.com, brulosophy.com, üretici siteleri) robots.txt veya JS nedeniyle çekilemeyeceği yalnız denenerek bilinir.

## 2. Citations API, search_result blokları, document blokları (kendi RAG'ın)

### Takeaway
Kendi verdiğin `document` (düz metin / PDF / özel içerik) veya `search_result` bloklarında citations açılınca alıntılar cümle (ya da senin bloğun) sınırında, birden çok ardışık cümleyi kapsayabilecek şekilde ve garanti geçerli işaretçilerle döner; `cited_text` çıktı tokenı sayılmaz. Ancak citations, structured outputs (`output_config.format`) ile AYNI istekte kullanılamaz (400) — CEV'in JSON özetleyicisi doğrudan citations'a geçemez.

### Cited Findings
- Tüm aktif modeller citations destekler; belgeler PDF, düz metin veya özel içerik olabilir; bir istekteki belgelerin "all or none" citations açık olmalı. Düz metin ve PDF cümlelere bölünür ("cite a single sentence or chain together multiple consecutive sentences to cite a paragraph or longer passage"); özel içerik bloklarında ek bölme yapılmaz. — [Citations](https://platform.claude.com/docs/en/build-with-claude/citations)
- Konum tipleri: düz metin → `char_location` (0-tabanlı karakter aralığı), PDF → `page_location` (1-tabanlı sayfa), özel içerik → `content_block_location`. — [Citations](https://platform.claude.com/docs/en/build-with-claude/citations)
- Güvenilirlik ve maliyet: "citations are guaranteed to contain valid pointers to the provided documents"; "`cited_text` does not count toward your output tokens"; sonraki turlarda geri gönderilince input tokenı da sayılmaz; citations açmak "slight increase in input tokens" getirir. Anthropic değerlendirmelerinde citations özelliği, istemle alıntı istemekten "significantly more likely to cite the most relevant quotes". — [Citations](https://platform.claude.com/docs/en/build-with-claude/citations)
- Uyumsuzluk: "If you enable citations on any user-provided document (`document` blocks or `search_result` blocks) and also include the `output_config.format` parameter… the API returns a 400 error." Önerilen yol: her alan için bir satır yazdırıp kodda ayrıştırmak ("Get structured data with citations"). — [Citations](https://platform.claude.com/docs/en/build-with-claude/citations); [Structured outputs – Feature compatibility](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)
- Citations prompt caching, token counting ve batch ile birlikte çalışır; kaynak belgelere `cache_control` konabilir. — [Citations](https://platform.claude.com/docs/en/build-with-claude/citations)
- PDF'ler base64, URL ya da `file_id` ile verilebilir; taranmış (metni çıkarılamayan) PDF'ler alıntılanamaz. — [Citations](https://platform.claude.com/docs/en/build-with-claude/citations)
- `search_result` bloğu: `source`, `title`, `content` (yalnız text blokları); iki kullanım: (1) istemci aracının `tool_result`'ı olarak, (2) kullanıcı mesajında üst düzey içerik olarak ("Pre-fetched content from your search infrastructure"). Citations search_result'ta VARSAYILAN KAPALI, `citations: {enabled: true}` ile açılır. Alıntı birimi tam metin bloğudur ("Claude cites whole blocks, not substrings within a block"); daha ince alıntı için içeriği küçük bloklara böl. `search_result_location` alanları: `cited_text`, `source`, `title`, `search_result_index`, `start_block_index`, `end_block_index`. — [Search results](https://platform.claude.com/docs/en/build-with-claude/search-results)
- Bir `tool_result` içinde search_result varsa tüm bloklar search_result olmalı (karışık → doğrulama hatası); search_result'a `cache_control` konabilir. — [Search results](https://platform.claude.com/docs/en/build-with-claude/search-results)
- API sürümü `2026-10-21` ile: kullanıcı mesajında (doğrudan ya da search_result içinde) boş olmayan `citations` dizili `text` bloğu göndermek 400 verir; assistant mesajına `document` koymak 400 verir. Uygulamanın kullandığı `2023-06-01` sürümünde bu kurallar yok. — [Versioning](https://platform.claude.com/docs/en/api/versioning)

### Inferences
- Tarayıcıdaki PWA, CORS yüzünden üçüncü taraf sayfaları kendisi çekip `document` olarak veremez (tarayıcı dışı bir proxy olmadan) — bu nedenle "kendi RAG'ın" yolunun pratik kaynağı web_fetch'in döndürdüğü düz metindir. İki aşamalı tasarım: (a) Haiku 5.5 + web_search + web_fetch ile kaynak sınıfı başına tam metinleri topla; (b) özetleyici/doğrulayıcıya bu metinleri `document` (citations açık) olarak ver.
- Structured outputs ↔ citations çakışması yüzünden CEV özetleyicisi iki yoldan birini seçmeli: (1) JSON özetleyici aynen kalır, alıntı doğrulaması yerel metin eşleştirmesine taşınır (S–M efor, en az risk); (2) citations'lı bir "kanıt çıkarma" çağrısı eklenir, satır-başına-madde biçimi kodda ayrıştırılır (M efor; dondurulmuş doğrulayıcı imzası değişmeden yeni ön adım). Seçenek 1 daha az çağrı ve daha az yeniden dondurma gerektirir.
- Özel içerik (custom content) belgeler, kaynağı paragraf/blok olarak bölüp alıntı sınırını uygulamanın kontrol etmesine izin verir — CEV'in "alıntı ↔ madde" eşlemesini deterministik yapar.

### Gaps
- Citations'ın Türkçe soru + İngilizce kaynakla davranışı (çapraz dil alıntı kalitesi) belgelenmemiş; deneme gerekir.
- Citations'ın max_tokens / düşünme tokenlarıyla etkileşimi için ayrı bir sınır belgelenmemiş.
- `web_fetch` aracında `citations: {enabled: true}` ile `output_config.format` aynı istekte kullanılırsa 400 dönüp dönmediği belgelenmemiş (uyumsuzluk metni yalnız kullanıcı tarafından verilen `document` ve `search_result` bloklarını adlandırıyor; web_search citations'ı ise her zaman açık). Bulamadım — denemeyle teyit edilmeli.

## 3. Message Batches API (değerlendirme koşuları için)

### Takeaway
Batch API girdi+çıktıda %50 indirim verir, web_search/web_fetch dahil tüm server tool'ları ve structured outputs'u destekler, çoğu batch 1 saatten kısa sürer (en fazla 24 saat); ama her istek bağımsız işlendiği için CEV'in "sorgu üret → 4 arama → özet → kapsama → doğrula → onar → yeniden doğrula" zinciri tek batch'e sığmaz — her aşama için ayrı batch (en az 5–7 tur) gerekir ve tarayıcıdan batch uç noktalarına erişim belgelenmemiştir.

### Cited Findings
- "reducing costs by 50 percent"; "most batches finishing in less than 1 hour"; sonuçlar tüm istekler bitince ya da 24 saat sonra alınır; 24 saatte bitmeyen istekler `expired` olur ve ücretlendirilmez; sonuçlar 29 gün saklanır; batch başına ≤100.000 istek veya 256 MB. — [Batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing)
- Batch fiyatları (MTok): Opus 5.5 $2 / $10; Sonnet 5.5 $1 / $5; Haiku 5.5 $0,05 / $0,25 (≤100k istem), $0,25 / $1,25 (>100k); Fable 5.1 $5 / $25. — [Batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing)
- Batch'te çalışanlar: "Tool use, including all server tools (web search, web fetch, code execution, MCP connectors, advisor, and tool search)", çok-turlu konuşmalar, thinking, "Most beta features"; "The batch worker runs the same server-side agentic loop as the synchronous Messages API", daha yüksek iterasyon sınırıyla; sınıra ulaşınca `pause_turn`. Desteklenmeyen parametreler: `stream: true`, `speed`, `fallbacks`, `max_tokens: 0`. — [Batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing); [Server tools](https://platform.claude.com/docs/en/agents-and-tools/tool-use/server-tools)
- Structured outputs batch ile çalışır ("Process structured outputs at scale with a 50 percent discount"). — [Structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)
- Web search ve web fetch batch'te normal fiyatla ücretlendirilir (arama başına indirim yok); "the Batches API throttles web search requests for each organization, so large batches with many searches might take longer to complete." — [Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool); [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)
- Batch'te önbellek isabeti "best-effort"; "Users typically experience cache hit rates ranging from 30 percent to 98 percent"; batch'ler 5 dakikadan uzun sürebileceği için 1 saatlik önbellek önerilir; indirimler üst üste biner. — [Batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing); [Pricing](https://platform.claude.com/docs/en/about-claude/pricing)
- `params` doğrulaması asenkron yapılır; hatalar ancak batch bitince görünür; `custom_id` 1–64 karakter. Batch API hız sınırları tüm modellerde ortak (ör. bir kademede 1.000 RPM, kuyrukta 200.000 istek). — [Batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing); [Rate limits](https://platform.claude.com/docs/en/api/rate-limits)
- `output-300k-2026-03-24` beta başlığı yalnız batch'te Opus 5.5/Sonnet 5.5/Haiku 5.5 için max_tokens'ı 300.000'e çıkarır. — [Batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing)

### Inferences
- Koşu #8 22,90 $ idi; token kısmı %50 iner, arama ücreti (10 $/1000) inmez. Koşu başına arama sayısı ≈ 55 soru × 4 çağrı × ≤3 arama ≈ ≤660 arama ≈ ≤6,6 $ (VARSAYIM; gerçek sayım loglardan alınmalı). Bu durumda tasarruf ≈ (23 − ~5) × 0,5 ≈ 8–9 $/koşu (VARSAYIM). 200 $ tavanında ~2 ek koşu demek.
- Zincir aşamalı olduğu için: aşama 1 batch (55 sorgu üretimi) → bitince aşama 2 batch (220 arama çağrısı) → … ; her aşama "çoğu 1 saatten kısa" ise koşu 5–7 saate uzar (24 saate kadar risk). Gerçek koşu sürerken CC'ye sprint verilmemesi kuralı düşünülünce, uzun süre bir dezavantaj.
- Dondurulmuş denetleyici imzaları değişmeden yalnız taşıma katmanı değişir; ama asenkron doğrulama hatası (koşu sonunda görülen 400) ve `expired` istekleri yeni bir "eksik veri" türü yaratır → puanlama koşudan önce yazıldığı için "expired = düşen" mi sayılacağı ÖNCEDEN karara bağlanmalı.
- Tarayıcıdan batch: sonuç dosyası JSONL; telefonda saatlerce sürecek bir polling akışı (ekran uyanık tutma / push) gerekir. CORS başlıklarının batch uç noktalarında da döndüğü belgelenmemiş → küçük bir denemeyle teyit edilmeli (DENE, ama önce düşük maliyetli tek istekli batch).
- Karar: DENE (yalnız değerlendirme koşuları için, M efor); günlük tek-soru kullanımında ALMA (gecikme kabul edilemez).

### Gaps
- Batch uç noktalarının tarayıcı CORS / `anthropic-dangerous-direct-browser-access` davranışı belgelenmemiş. Bulamadım.
- Batch'teki "higher per-turn iteration limit" değerinin sayısı belgelenmemiş.

## 4. Prompt caching (fiyat, TTL, asgari uzunluk, CEV'deki tasarruf)

### Takeaway
Opus 5.5 ve Sonnet 5.5'te önbellek okuması taban girdi fiyatının 0,05 katı (Opus 5.5: $0,20/MTok), Haiku 5.5'te 0,1 katı; yazma 5 dk TTL için 1,25×, 1 saat TTL için 2×; asgari önbelleklenebilir uzunluk 5.5 ailesinde 512 token. CEV'in dondurulmuş, her soruda aynı görev/denetleyici metinleri ideal aday — ama araç tanımı (allowed_domains) değişince tüm önbellek geçersizleştiği ve paralel isteklerde önbellek ancak ilk yanıt başladıktan sonra oluştuğu için kazanç çağrı tipine göre değişir.

### Cited Findings
- Fiyat tablosu (MTok): Opus 5.5 taban $4, 5 dk yazma $5, 1 sa yazma $8, okuma $0,20, çıktı $20; Sonnet 5.5 $2 / $2,50 / $4 / $0,10 / $10; Haiku 5.5 (≤100k) $0,10 / $0,125 / $0,20 / $0,01 / $0,50. Dipnot: "Cache hits and refreshes on Claude Opus 5.5 and Claude Sonnet 5.5 are priced at 0.05x the base input price." — [Pricing](https://platform.claude.com/docs/en/about-claude/pricing); [Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)
- Sonnet 5.5 okuma fiyatı yakın zamanda $0,20'den $0,10'a indirildi (release notes). — [Release notes](https://platform.claude.com/docs/en/release-notes/overview)
- Asgari uzunluk: "512 tokens for Claude Fable 5.1, … Claude Opus 5.5, Claude Opus 5, Claude Sonnet 5.5, … and Claude Haiku 5.5"; daha kısa istemler `cache_control` olsa da hatasız biçimde önbelleksiz işlenir (`cache_creation_input_tokens` ve `cache_read_input_tokens` 0 kalır). — [Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)
- İki yöntem: istek düzeyinde tek `cache_control` ile "automatic caching" (son önbelleklenebilir bloğa kırılma noktası koyar) veya blok düzeyinde açık kırılma noktaları (en fazla 4); 20 blokluk geri bakma penceresi. — [Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)
- Hiyerarşi `tools` → `system` → `messages`; "Modifying tool definitions (names, descriptions, parameters) invalidates the entire cache"; web search'ü açıp kapamak sistem ve mesaj önbelleğini bozar; `output_config.effort` değişikliği mesaj bloklarını her zaman bozar; `output_config.format` değişikliği de önbelleği geçersiz kılar. — [Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching); [Structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)
- "For concurrent requests, note that a cache entry only becomes available after the first response starts. If you need cache hits for parallel requests, wait for the first response before sending subsequent requests." — [Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)
- Önbellek workspace düzeyinde izole (Claude API'de); kuruluşlar arası asla paylaşılmaz. — [Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)
- Hız sınırı avantajı: ITPM'e yalnız `input_tokens` + `cache_creation_input_tokens` sayılır, `cache_read_input_tokens` sayılmaz. — [Rate limits](https://platform.claude.com/docs/en/api/rate-limits)
- Cache diagnostics artık beta değil: isteğe `diagnostics` nesnesi eklenince ardışık istekler karşılaştırılıp önekin nerede ayrıştığı raporlanır; desteklenen modeller arasında opus-5-5, sonnet-5-5, haiku-5-5 var. — [Cache diagnostics](https://platform.claude.com/docs/en/build-with-claude/cache-diagnostics); [Release notes](https://platform.claude.com/docs/en/release-notes/overview)
- `max_tokens: 0` ile önbellek ön-ısıtma (pre-warming) var, ama batch içinde desteklenmez. — [Batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing)

### Inferences
- Örnek hesap (VARSAYIM: 5.000 tokenlık sabit önek, Opus 5.5, 55 soru × 2 doğrulama = 110 çağrı, 1 saat TTL): önbelleksiz 110 × 5.000 × $4/MTok = 2,20 $; önbellekli 1 yazma (5.000 × $8/MTok = 0,04 $) + 109 okuma (109 × 5.000 × $0,20/MTok ≈ 0,11 $) ≈ 0,15 $ → ≈ 2 $/koşu tasarruf. Gerçek önek uzunlukları uygulama loglarındaki `cache_read_input_tokens` ile ölçülmeli.
- 4 paralel arama çağrısının her biri farklı `allowed_domains` taşıdığı için her sınıfın önbelleği ayrı; aynı soru içinde birbirine yardım etmezler, ama sorular arasında sınıf başına isabet mümkün (TTL içinde). 5 dk TTL, ardışık sorular arasında 5 dakikadan uzun süre geçiyorsa düşer → değerlendirme koşusunda 1 saat TTL daha güvenli (yazma 2×, ama tek yazma + çok okuma ile kâr; "caching pays off after… two cache reads for the 1-hour").
- Doğrulayıcı → onarım → ikinci doğrulama sıralı olduğu için aynı soru içinde de isabet alır. Effort veya şema her çağrı tipinde sabit tutulmalı; aksi halde önbellek sessizce kırılır (cache diagnostics bunu gösterir).
- Uygulama zaten `cache_control: {type:'ephemeral'}` kullanıyor (satır ~32131); öneri: (1) 1 saat TTL seçeneği değerlendirme koşusunda, (2) `usage.cache_read_input_tokens` > 0 olup olmadığının koşu raporuna yazılması, (3) cache diagnostics'in bir kez açılıp ıraksama noktasının görülmesi. Karar: AL (S efor).

### Gaps
- Brewmaster'daki sabit görev/denetleyici metinlerinin gerçek token uzunlukları bu araştırmada ölçülmedi (dosya tam okunmadı); 512 token altındaysa önbellek hiç devreye girmez.

## 5. Structured outputs, stop_reason, effort/düşünme, token sayımı, kullanım/maliyet API'si, hız sınırları, "400 workspace" hatası

### Takeaway
Özetleyicinin boş/eksik çıktısının belgelenmiş en olası nedeni: Opus 5.5'te düşünme kapatılamaz ve düşünme tokenları `max_tokens`'a dahildir; uzun düşünme bütçeyi yiyince `stop_reason: "max_tokens"` ile metin bloğu "truncated or missing" gelir — çözüm her yanıtta `stop_reason` + `usage.output_tokens` kaydı, daha yüksek `max_tokens` ve/veya daha düşük `effort`. ## 6. Tarayıcıdan doğrudan erişim, anahtar güvenliği, alternatifler (Cloudflare Worker proxy)

### Takeaway
Anthropic belgeleri API'nin arka uçtan çağrılmasını öneriyor; tarayıcıdan (CORS) çağrı ancak `anthropic-dangerous-direct-browser-access: true` başlığıyla kabul ediliyor ve "internal tools / development" gibi güvenilir kullanıcı senaryolarında kabul edilebilir sayılıyor. Tek kullanıcılı Brewmaster için en ucuz belgelenmiş önlemler: anahtarı ayrı bir workspace'e kapsamlamak + o workspace'e aylık harcama limiti + anahtar süresi (expiration). Cloudflare Worker proxy ücretsiz katmanda teknik olarak yeterli, ama tek kullanıcı için güvenlik kazancı sınırlı ve altyapı ekliyor.

### Cited Findings
- "Call the Claude API from your own back end, not from code that runs in your users' browsers. Anyone who uses a webpage can read an API key in that page's code." CORS isteği yalnız `anthropic-dangerous-direct-browser-access: true` başlığıyla kabul edilir (TypeScript SDK'da `dangerouslyAllowBrowser: true`). — [Authentication – Browser-based applications](https://platform.claude.com/docs/en/manage-claude/authentication)
- SDK rehberi, tarayıcı kullanımının riskli olmayabileceği durumları sayar: "Internal tools… where the users are trusted" ve "Development or debugging purpose… provided the credentials are short-lived… or are frequently rotated"; ZDR veya Compliance API'li organizasyonlarda tarayıcı istekleri 401 ile reddedilir. — [TypeScript SDK – Browser usage](https://platform.claude.com/docs/en/cli-sdks-libraries/sdks/typescript)
- CORS desteği 2024-08-22'de eklendi ("returning CORS headers in the API responses"). — [Release notes](https://platform.claude.com/docs/en/release-notes/overview)
- Anahtar türleri: kişisel anahtar, servis hesabı anahtarı (2026-08-27'den beri), legacy workspace anahtarı; anahtar tek workspace'e kapsamlanabilir ("lets you skip setting a workspace ID manually"). Süre seçenekleri: 3 saat, 1 gün, 7 gün, 30 gün, özel, "Never"; süresi dolan anahtar 401; süre sonradan değiştirilemez; 7+ gün ömürlü anahtarlar için uyarı e-postası. — [Authentication](https://platform.claude.com/docs/en/manage-claude/authentication)
- Kimlik doğrulama başlığı: `Authorization: Bearer <key>` (önerilen) ya da "legacy `x-api-key`" (hâlâ kabul ediliyor). — [Authentication](https://platform.claude.com/docs/en/manage-claude/authentication)
- Workspace'ler ayrı harcama limiti ve uyarı eşiği taşıyabilir (Console ▸ Workspaces ▸ Spend limits); organizasyon başına en fazla 100 workspace. — [Workspaces](https://platform.claude.com/docs/en/manage-claude/workspaces)
- IP allowlisting (beta, 2026-11-05): izin listesi dışından gelen istek 403 alır; organizasyon başına ≤1.000 IPv4/IPv6/CIDR girdisi; "if an API key is leaked, it is much harder for an attacker to use the key." — [IP allowlisting](https://platform.claude.com/docs/en/manage-claude/ip-allowlist); [Release notes](https://platform.claude.com/docs/en/release-notes/overview)
- Cloudflare Workers Free: 100.000 istek/gün, istek başına 10 ms CPU ("Waiting on network requests… does not count toward CPU time"), HTTP tetiklemeli Worker için süre (duration) sınırı yok ("As long as the client remains connected, the Worker can continue processing… and streaming a response body"), istek başına 50 alt istek; Paid plan aylık $5'tan başlar. — [Cloudflare Workers limits](https://developers.cloudflare.com/workers/platform/limits/); [Cloudflare Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/)

### Inferences
- AL (S efor): Console'da yalnız Brewmaster için bir workspace + o workspace'e kapsamlı anahtar + aylık harcama limiti (ör. 200 $ kredi tavanına eşit) + 30 günlük süre. Bu hem sızıntı zararını sınırlar hem de "not scoped to a workspace" 400'ünü (bölüm 5) kökten önler. Not: harcama limitine ulaşınca gelen 400 mesajı da "workspace" içerir → uygulama mesajı doğru sınıflandırmalı.
- IP allowlist telefonda (mobil ağ, değişen IP) pratik değil → ALMA (kişisel kullanımda).
- Cloudflare Worker proxy (İZLE, M efor): Ücretsiz katman CEV yükünü (soru başına ~10 çağrı) rahat taşır; uzun Opus yanıtlarında CPU sınırı sorun değil çünkü ağ beklemesi sayılmaz. Ama proxy'nin kendisi de bir sırla korunmalı (tarayıcıda yine bir gizli değer durur) → tek kullanıcı için kazanç esas olarak "Anthropic anahtarı cihazda değil, iptal edilebilir ikinci anahtar cihazda" olur; push cron işi (c) için zaten bir Worker kurulursa, aynı Worker'a eklemek mantıklı.
- `x-api-key` legacy ama destekleniyor; `Authorization: Bearer`'a geçiş zorunlu değil. API sürümünü 2026-10-21'e yükseltmek isteğe bağlı; yükseltilirse `temperature/top_p/top_k` gönderen istekler ve kullanıcı mesajında citations taşıyan text blokları 400 verir (uygulamada `temperature` parametresi bulunmadı; tek eşleşme bir veri metni).

### Gaps
- Cloudflare AI Gateway'in Anthropic anahtarını sunucu tarafında saklama (BYOK) ayrıntıları bu turda doğrulanmadı.
- Batch ve Files uç noktalarının CORS davranışı belgelenmemiş.

## 7. Files API, memory tool, context editing, Agent Skills, code execution, programmatic tool calling, tool search, MCP connector, advisor, message threads

### Takeaway
Bu özelliklerin çoğu uzun, çok-turlu, çok-araçlı ajan iş akışları için; CEV ise tek-turlu, az-araçlı, dondurulmuş adımlardan oluşan bir boru hattı. Yalnız code execution (web araçlarının yeni sürümleriyle ücretsiz) ve dolaylı olarak advisor ilginç; geri kalanı Brewmaster için ALMA ya da İZLE.

### Cited Findings
- Code execution: Python + Bash, kum havuzu; "The container has no internet access"; sürümler `code_execution_20250825`, `code_execution_20260120` (REPL kalıcılığı + programmatic tool calling), `code_execution_20260521`; konteyner verisi 30 güne kadar saklanır. Fiyat: `web_search_20260209+` veya `web_fetch_20260209+` istekte varsa ek ücret yok; aksi halde organizasyon başına ayda 1.550 ücretsiz saat, sonra konteyner-saati $0,05, en az 5 dakika; dosya eklenirse araç çağrılmasa da süre ücretlenir. — [Code execution tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/code-execution-tool); [Pricing](https://platform.claude.com/docs/en/about-claude/pricing)
- Programmatic tool calling (stable): Claude, araçlarını kod konteynerinden çağırır; "cutting model round trips and token use in multi-tool workflows"; araca `allowed_callers: ["code_execution_20260120"]` eklenir. — [Programmatic tool calling](https://platform.claude.com/docs/en/agents-and-tools/tool-use/programmatic-tool-calling)
- Tool search (stable): "Scale to hundreds or thousands of tools". — [Tool search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/tool-search-tool)
- Memory tool (stable): bellek dosya işlemlerini uygulamanın kendisi yürütür (istemci tarafı). — [Memory tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
- Context editing (beta, `context-management-2025-06-27`): büyüyen konuşma bağlamını otomatik yönetir. — [Context editing](https://platform.claude.com/docs/en/build-with-claude/context-editing)
- Files API (stable): dosyayı bir kez yükleyip `file_id` ile kullan; dosya silinene ya da `expires_in_seconds` (3.600 sn'den başlar) dolana kadar saklanır; Files API isteği en fazla 500 MB. — [Files API](https://platform.claude.com/docs/en/build-with-claude/files); [Errors – Request size limits](https://platform.claude.com/docs/en/api/errors)
- Agent Skills (API, `skills-2025-10-02`): code execution içinde çalışır; hazır Anthropic skill'leri `pptx`, `xlsx`, `docx`, `pdf`; özel skill'ler Skills API ile yüklenir. — [Skills in the API](https://platform.claude.com/docs/en/build-with-claude/skills-guide)
- MCP connector (beta, `mcp-client-2026-09-15` / `mcp-client-2025-11-20`): Messages API'den uzak MCP sunucularına bağlanma. — [MCP connector](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector)
- Advisor tool (beta, `advisor-tool-2026-03-01`): hızlı/ucuz "executor" model, ortada daha zeki "advisor" modele danışır; advisor ayrı çıkarım olarak kendi model fiyatından faturalanır; en yeni Opus advisor olduğunda tavsiye metni şifreli (`advisor_redacted_result`) döner; belge: "weaker fit for single-turn Q&A (nothing to plan)". — [Advisor tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool)
- Message threads (beta, `message-threads-2026-08-12`, 2026-11-02): konuşma sunucuda tutulur, sonraki istek yalnız yeni mesajları gönderir; thread son istekten 5 dakika sonra sona erer; içerik en geç 1 saat içinde silinir. — [Message threads](https://platform.claude.com/docs/en/build-with-claude/message-threads); [Release notes](https://platform.claude.com/docs/en/release-notes/overview)
- Server-side fallback (beta, `server-side-fallback-2026-07-01`): `fallbacks: "default"` ya da ≤3 modellik liste; reddedilen istek sunucuda başka modelle yeniden denenir; batch'te desteklenmez; "Claude Haiku 5.5 has neither server-side fallback nor fallback credit". — [Refusals and fallback](https://platform.claude.com/docs/en/build-with-claude/refusals-and-fallback)
- PDF desteği: PDF'ler base64, URL veya `file_id` ile verilebilir (citations'da `page_location`). — [Citations](https://platform.claude.com/docs/en/build-with-claude/citations); [PDF support](https://platform.claude.com/docs/en/build-with-claude/pdf-support)

### Inferences
- Code execution: İZLE. Demleme matematiği (IBU, OG, karbonasyon) uygulamada zaten deterministik JS; modele kod çalıştırtmak doğrulanabilirliği azaltır. Tek gerçek fayda dinamik filtrelemede (bölüm 1), o da ücretsiz.
- Advisor: İZLE/ALMA. Teorik olarak "Haiku 5.5 executor + Opus 5.5 advisor" özetleyici maliyetini düşürebilir, ama belge tek-tur Soru-Cevap için zayıf uyum diyor, tavsiye metni şifreli döndüğü için CEV'in "her maddeyi Claude etiketler" şeffaflık kuralıyla çelişiyor ve beta.
- Files API: ALMA (şimdilik). Kaynak PDF'leri (ör. BJCP kılavuzu) bir kez yükleyip `file_id` ile citations'lı belge olarak vermek mümkün, ama tarayıcıdan Files uç noktası CORS'u belgelenmemiş ve web_fetch PDF'i zaten URL'den alıyor; ileride DERSLER sekmesi (b) için yeniden bakılabilir.
- Skills, MCP connector, tool search, memory tool, context editing, programmatic tool calling, message threads: ALMA — çok-araçlı/uzun konuşmalı ajanlar için; CEV'in 4–7 kısa çağrısında kazanç yok, ek beta riski var.
- Server-side fallback: İZLE — reddin CEV'de sorun olduğu ölçülmedi; Haiku 5.5 (arama çağrıları) için zaten yok.

### Gaps
- (Kapatıldı) PDF sınırları: istek başına ≤128 MB (birinci taraf API) ve ≤600 sayfa (bağlam penceresi 1M'nin altındaysa 100); sayfa başına tipik 1.500–3.000 token, ek PDF ücreti yok; PDF URL ile de verilebilir — [PDF support](https://platform.claude.com/docs/en/build-with-claude/pdf-support). web_fetch'in `content_too_large` hatası bu sınırlara bağlı. Bir PDF'in 30–50 sayfası bile 50k–150k token eder → Haiku 5.5'te 100k eşiği kolayca aşılır (fiyat 5×), web_fetch PDF'lerinde `max_content_tokens` uygulanmadığı belgeli olduğundan PDF çekmeyi kısıtlamak (ör. yalnız belirli alan adları) gerekir.
- Hangi kaynak PDF'lerinin (üretici teknik föyleri) CEV'de sık çıktığı ölçülmedi.

## 9. Değerlendirme araçları (Console evaluation tool, promptfoo, inspect-ai, DeepEval)

### Takeaway
Hiçbiri CEV'in asıl zor kısmını (Claude'un tüm maddeleri kör alt-etiketçilerle etiketlemesi, koşudan önce yazılmış puanlama, Clopper–Pearson üst sınır kapısı) hazır sunmuyor; en fazla koşu altyapısı (tekrarlanabilir YAML koşu, batch, maliyet takibi) olarak işe yarar ve hepsi tarayıcı dışı (Node/Python) çalışır — Brewmaster'ın "gerçek harcama yalnız Kaan düğmeye basınca, uygulama içinde" kuralıyla çelişir.

### Cited Findings
- Anthropic'in değerlendirme rehberi üç not verme türü sayar: kod tabanlı ("Fastest and most reliable"), insan ("Avoid if possible"), LLM tabanlı ("Test to ensure reliability first, then scale"); LLM değerlendiricide düşünmenin açık olması önerilir; "Prioritize volume over quality". — [Define success criteria and build evaluations](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests)
- İngilizce `test-and-evaluate/eval-tool` adresi 2026-11-07'de "Define success criteria and build evaluations" sayfasına yönleniyor; Console'un "Evaluate" aracı için güncel İngilizce sayfa bulunamadı (yerelleştirilmiş eski sayfalar duruyor, ör. zh-TW/de/ru). — [platform.claude.com/docs/en/test-and-evaluate/eval-tool](https://platform.claude.com/docs/en/test-and-evaluate/eval-tool); [zh-TW eval-tool](https://platform.claude.com/docs/zh-TW/test-and-evaluate/eval-tool)
- promptfoo Anthropic sağlayıcısı: `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`, Fable 5.1 kimliklerini listeler; `web_search_20250305/20260209/20260318`, `web_fetch_20250910…20260318` (citations, `max_content_tokens`, `allowed_domains`), `effort`, `cache_control`, structured outputs (promptfoo `output_format`'ı `output_config.format`'a eşler ve `structured-outputs-2025-11-13` beta bayrağını ekler) ve `llm-rubric` gibi model-notlu doğrulamaları destekler. — [promptfoo – Anthropic provider](https://www.promptfoo.dev/docs/providers/anthropic/)
- Inspect (UK AISI) Anthropic batch API'yi destekler (`--batch`); kendi uyarısı: "evaluations with a large and/or variable number of generations (e.g. agentic tasks) can often take many hours or days due to both the large number of batches that must be waited on and the path dependency created between requests". — [Inspect – Batch Mode](https://inspect.aisi.org.uk/models-batch.html)
- DeepEval: Apache 2.0 lisanslı açık kaynak; "Faithfulness" metriği LLM-as-a-judge ile çıktının `retrieval_context` ile uyumunu ölçer, `truths_extraction_limit`, `penalize_ambiguous_claims` gibi ayarları var. — [DeepEval – Faithfulness](https://deepeval.com/docs/metrics-faithfulness)

### Inferences
- İZLE (M–L efor): promptfoo, CEV'in sabit soru setini Node'da tekrarlanabilir koşmak ve sürümler arası regresyon karşılaştırması için en uygun aday (Claude 5.5 + web araçları desteği belgeli). Ama CEV'in dondurulmuş denetleyicileri ve etiketleme protokolü zaten uygulama içinde; yeniden yazmak imza dondurma kurallarına yeni risk getirir.
- Inspect'in kendi uyarısı CEV'in çok-aşamalı zinciri için batch'in saatlerce sürebileceğini doğruluyor (bölüm 3 ile tutarlı).
- DeepEval Faithfulness, CEV doğrulayıcısının yaptığı işin (madde ↔ kaynak uyumu) genel bir sürümü; CEV'in kanıt-gücü ve kapı mantığını içermez → ALMA (yalnız fikir kaynağı).
- Değerlendirmenin asıl iyileştirilebilecek yeri araç değil veri: web_fetch tam metni ile yerel alıntı eşleştirmesi "kod tabanlı not verme"ye kayar — Anthropic rehberinin en güvenilir saydığı tür.

### Gaps
- promptfoo ve Inspect lisansları bu turda doğrulanmadı (GitHub API erişimi bu oturumda kapalıydı).
- Console Evaluate aracının 2026 Kasım itibarıyla hâlâ ürün içinde olup olmadığı belgelerden doğrulanamadı.
